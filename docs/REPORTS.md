## Швидкий запуск після розпакування

Відкрийте PowerShell у папці computer-inventory та виконайте:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[test,dev]"
.\.venv\Scripts\python.exe -m inventory_service.main --demo
.\.venv\Scripts\python.exe -m pytest
```

Повні сценарії кожної роботи описані в README.md проєкту.
