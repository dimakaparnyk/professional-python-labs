# Облік комп’ютерної техніки

Курс «Професійний Python», лабораторна №1, варіант **13**.

## Можливості

Пристрій: інвентарний номер, тип, виробник, модель, вартість у гривнях.
Додавання з перевіркою унікальності номера; пошук за чотирма текстовими
полями; фільтрація за повною назвою виробника; середня та загальна вартість;
найдорожчий пристрій; сортування за вартістю. Пошук не залежить від регістру.
Грошові обчислення виконуються через Decimal. За однакової максимальної
вартості повертається перший пристрій. Для порожнього списку суми й середнє
дорівнюють нулю, найдорожчий пристрій відсутній.

Дані зберігаються лише в пам’яті до виходу. Файли, БД та API додаються
на наступних лабораторних після отримання відповідних завдань.

## Вимоги та встановлення (Windows PowerShell)

Python 3.11+; Git. Команди виконувати з кореня проєкту.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
```

Можна активувати середовище через `.\.venv\Scripts\Activate.ps1` і
далі писати `python` замість повного шляху. Якщо активація заблокована,
використовуйте наведений прямий шлях до Python середовища.

## Запуск

```powershell
.\.venv\Scripts\python.exe -m computer_inventory.main
.\.venv\Scripts\python.exe -m computer_inventory.main --demo
.\.venv\Scripts\computer-inventory.exe --demo
```

Без `--demo` відкривається меню з порожнім списком; команда 1 додає пристрій.
Демо містить 4 пристрої, сума 92700.00 грн, середнє 23175.00 грн,
найдорожчий — INV-003, Dell Latitude 5440, 45000.00 грн.

## Перевірка

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

## Структура

- `src/computer_inventory/models.py` — dataclass Device та перевірки полів.
- `src/computer_inventory/services.py` — незалежна від меню бізнес-логіка.
- `src/computer_inventory/main.py` — введення, меню, демонстрація, точка входу.
- `tests/test_inventory.py` — функціональні й граничні перевірки.
- `pyproject.toml` — метадані, setuptools, src-layout і консольна команда.
- `docs/GITHUB.md` — покрокове завантаження на GitHub.
